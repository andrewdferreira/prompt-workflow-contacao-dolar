# Prompt - Workflow: Contação do Dolar

*Quero criar uma automação no N8N para enviar mensagens quando o dolar estiver bom para venda.*

## 📋 Público ou responsável:
Uma pessoa que recebe seu salário em dólar.

## Resultado esperado:
Receber notificação quando o dolar estiver acima de um determinado valor.

## 🛠️ Ferramentas envolvidas:
Whatsapp ou Telegram e API de cotações

## 🔄 Fluxo desejado:
1. Receber informações sobre a API
2. Colocar essas informações da variável e verificar valor
3. Enviar mensagem sobre o valor do dolar e se está bom para a compra. 

## Regras importantes:
Se o dolar estiver com um valor baixo, ignorar
